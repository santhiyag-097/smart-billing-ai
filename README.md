# AI-Based Smart Billing System 🛒

## 📌 Description
This project is a Smart Billing System with Theft Detection using Java Spring Boot and JavaScript.

## 🚀 Features
- Add items to cart
- Auto bill calculation
- Theft detection system
- Simple UI interface

## 🛠️ Tech Stack
- Java (Spring Boot)
- HTML, JavaScript

## ▶️ How to Run
1. Run DemoApplication.java
2. Open http://localhost:8081

## 📷 Output
- Displays total bill
- Alerts if theft detected
